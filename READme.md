# Student Management System 🎓

A beginner-friendly Student Management System built using Python.

## ✨ Features

- Add student records
- View all students
- Search students by roll number
- Update student information
- Delete student records
- Simple menu-driven interface

## 🛠️ Technologies Used

- Python
- Dictionaries
- Functions
- Conditional Statements
- Loops

## 🚀 How to Run

1. Download or clone this repository.
2. Open `student_management.py`.
3. Run the Python file.
4. Choose an option from the menu.

## 📚 What I Learned

This project helped me practice Python functions, dictionaries, loops, conditional statements, user input, and basic CRUD operations.
